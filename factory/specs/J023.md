# J023 찾기 화면에 DESIGN.md 적용 (계획 P003 작업 C)

`frontend/src/Search.tsx`의 모양만 `DESIGN.md`(4장 컴포넌트 대응, 7장 찾기)에 맞춘다. 동작·API·문구·aria-label은 바꾸지 않는다.

## 만들 것

컴포넌트는 `@/components/ui/`의 shadcn/ui, 아이콘은 `lucide-react`를 쓴다. 토큰 클래스만 쓰고 인라인 style·색상 값은 쓰지 않는다.

1. **폼 Card**: 검색 폼과 질문 폼을 `Card` 하나에 위아래로 둔다. 두 폼 사이에 `Separator` 하나.
   - 각 폼: `Label`(글자 `검색어`, `질문` 그대로, `htmlFor`로 입력에 연결) + `Input` + 오른쪽 `Button`(default, `type="submit"`, 글자 `검색`, `질문` 그대로).
   - 입력과 버튼을 함께 감싼 요소는 기본 세로, `sm:flex-row`로 sm 이상 가로 배치. 폼 자체여도 안쪽 div여도 된다.
2. **요청 중**: 해당 폼의 버튼은 지금처럼 disabled이고, 글자 앞에 `Loader2`(`animate-spin`)를 보인다. 버튼의 접근 가능한 이름은 그대로. `검색 중…`, `답변을 만드는 중…` 글자는 그대로 남긴다. 글자에는 `text-sm text-muted-foreground`.
3. **검색 결과**: `노트 결과`, `결정 사항 결과`(section `aria-label` 그대로) 영역은 각각 `Card`. section 안에 Card를 두거나 section이 Card 역할을 해도 된다.
   - 행은 노트를 여는 `Button variant="ghost"`. 넓이를 채우고(`w-full`, `justify-start`, `text-left`) 긴 글이 넘치지 않게 `h-auto whitespace-normal`.
   - 행 안: 제목 `font-medium` + 보조 글 `text-xs text-muted-foreground`. 노트 행은 제목 `title`, 보조 `snippet`. 결정 행은 제목 `text`, 보조 `note_title`.
4. **답변**: section `aria-label="답변"` 그대로, `Card`.
   - 답변 본문 `text-sm leading-7`.
   - 근거가 있으면 본문 아래 `근거` 줄: 머리글 글자 `근거`(`text-xs text-muted-foreground`, 이 글자만 있는 요소) + 근거 노트마다 `Button variant="outline" size="sm"`.
   - 근거가 없으면(`sources`가 빈 배열) 본문에 `text-muted-foreground`를 더하고 `근거` 줄은 그리지 않는다.
5. **오류**: `Alert variant="destructive"`(`role="alert"`, 문구 그대로). 제목은 `AlertTitle`, message와 problems는 `AlertDescription` 안. problems는 지금처럼 목록.
6. **결과 없음**: `없음` 문구(전체 결과 없음과 영역별 없음)는 점선 영역 `border border-dashed rounded-lg p-8 text-center`.
7. 화면 안 구역 사이 간격은 `gap-6`, 카드 안쪽은 DESIGN.md 3장을 따른다. 결과 영역 순서는 지금 그대로 (노트 결과 → 결정 사항 결과 → 답변).
