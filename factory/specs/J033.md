# J033 캘린더 화면 (P005 작업 C)

`DESIGN.md` v3의 캘린더(4장 "캘린더 월 격자"·"캘린더 날짜 패널", 7장 "캘린더")를 만든다. 데이터는 J031의 `GET /api/calendar`다. 새 npm 패키지 없이 `Date`와 `Intl`만 쓴다.

첫 시도 J032는 잠긴 수락 테스트가 2026-03 격자를 35일로 잘못 적어 막혔다. 2026-03은 3월 1일이 일요일이라 2026-02-23~2026-04-05, 6주 42일이다. 이번 수락 테스트는 그 기대값을 실제 달력으로 고쳤다.

## 1. `frontend/src/api.ts`

- `Todo`에 `due_date: string | null`을 더한다.
- `CalendarResult` 타입: `{ month: string; days: { date: string; notes: { id: number; title: string }[]; decisions: { text: string; note_id: number; note_title: string }[]; todos: { id: number; task: string; done: boolean; note_id: number; due: string | null; due_date: string }[] }[] }`.
- `fetchCalendar(month?: string): Promise<CalendarResult>`: `month`가 없으면 `/api/calendar`, 있으면 `/api/calendar?month=<month>`. 응답이 실패면 예외를 던진다 (`fetchWeekly`와 같은 방식).

## 2. `frontend/src/Calendar.tsx`

`export default function Calendar({ onOpenNote }: { onOpenNote: (id: number) => void })`와 순수 함수 `export function monthGrid(month: string): string[]`.

설계 (사람 합의): 상태는 `month`('YYYY-MM'), `selected`('YYYY-MM-DD'), result | loading | error, 요청 번호(늦은 응답 버림). `days` 배열은 date 키 맵으로 바꿔 칸에서 찾는다. 오늘은 **로컬** 날짜다 (`toISOString`을 쓰면 시간대에 따라 하루 어긋난다).

`monthGrid(month)`: 그 달을 덮는 주 단위 날짜 목록(`YYYY-MM-DD`). 월요일에 시작해 일요일에 끝나고 앞뒤 달 날짜를 포함한다. 6주 고정이 아니라 4~6주다. 예: 2026-11은 2026-10-26~2026-12-06 (42일), 2026-03은 2026-02-23~2026-04-05 (42일), 2026-02는 2026-01-26~2026-03-01 (35일).

### 월 이동 줄

`이전 달`·`다음 달` (`Button variant="outline" size="sm"`, `ChevronLeft`/`ChevronRight`), 가운데 제목 heading 'YYYY년 M월'(`text-lg font-semibold`), 오른쪽 `오늘` (outline sm). 로딩·오류 중에도 보이고 누를 수 있다. 처음 열면 이번 달이고 오늘이 선택돼 있다. 달을 옮기면 선택한 날은 그 달 1일이고, `오늘` 버튼은 오늘이 든 달과 오늘을 선택한다. `fetchCalendar`에는 항상 `month`를 넘긴다 (서버 시간대가 아니라 화면의 달을 기준으로).

### 월 격자

`Card` 안 `grid grid-cols-7`. 요일 머리글 월~일 (`text-xs text-muted-foreground`, 글자 한 자). 날짜 칸은 `button`이고 접근 가능한 이름은 `M월 D일, 노트 N, 결정 N, 할 일 N`이다 (0개여도 세 개수를 모두 쓴다).

칸 내용 (`DESIGN.md` 표): 위 날짜 숫자(`text-sm`), 아래 항목 점(`size-1.5 rounded-full`: 노트 `bg-primary`, 결정 `bg-muted-foreground`, 할 일 `border border-primary`)과 1024px 이상에서 첫 항목 제목 한 줄(`truncate text-xs`). 점은 항목 종류마다 하나다. 첫 항목은 노트 → 결정(`text`) → 할 일(`task`) 순서로 찾는다. 오늘은 숫자에 `bg-primary text-primary-foreground rounded-full`, 선택한 날은 칸에 `bg-accent`, 다른 달 날짜는 `text-muted-foreground/50`. 칸 높이 `min-h-12 lg:min-h-24`.

다른 달 날짜 칸을 누르면 그 달로 옮겨 그 날짜를 선택한다 (지금 달의 응답에는 그 날 데이터가 없어서 "기록 없음"으로 보이면 틀린 말이 되므로).

### 날짜 패널

격자 아래(1024px 이상은 오른쪽 `w-72`) `Card`. 제목 heading `M월 D일 (요일)`, 요일은 한 글자(`Intl.DateTimeFormat("ko-KR", { weekday: "short" })`). 항목이 있는 날은 구역(role=region) 3개 `노트`, `결정 사항`, `기한인 할 일`을 모두 보여 주고, 항목 없는 구역은 '없음'이라고 쓴다 (주간 정리와 같음). 각 행은 `Button variant="ghost"`이고 누르면 `onOpenNote(note_id)`(노트는 `id`)다. 완료한 할 일은 `line-through text-muted-foreground`.

항목이 전혀 없는 날은 구역 없이 점선 영역(`border border-dashed rounded-lg p-8 text-center`) "이 날짜에 기록이 없습니다".

### 상태

- 로딩: 격자·패널 자리에 `Skeleton` 3줄, 날짜 칸을 그리지 않는다 (개수가 0으로 보이면 틀린 정보다). 이전 달의 항목을 남기지 않는다.
- 오류: `Alert variant="destructive"`(role=alert) + `다시 시도` 버튼 (같은 달을 다시 부른다). 격자·패널은 그리지 않는다.
- 달을 바꾸는 중 늦게 온 응답(성공·실패 모두)은 버린다.

## 3. `frontend/src/App.tsx`

탭 배열 다섯 번째에 `{ tab: "calendar", label: "캘린더", icon: CalendarDays, onClick }`, `tab === "calendar"`이면 `<Calendar onOpenNote={openOriginNote} />`. 기존 탭 4개와 다른 화면은 바꾸지 않는다.
