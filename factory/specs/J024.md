# J024 주간 정리 화면에 DESIGN.md 적용 (계획 P003 작업 D)

`frontend/src/Weekly.tsx`의 모양만 DESIGN.md(4장 주간 정리·오류·빈 목록·로딩)에 맞춘다. 동작·API·문구·aria-label은 바꾸지 않는다.

## 만들 것

컴포넌트는 `src/components/ui/`의 것을 쓴다 (`@/components/ui/...`).

1. 주 이동 줄
   - `지난주`·`다음 주`: `Button variant="outline" size="sm"`, 글자 그대로. `지난주`에 lucide-react `ChevronLeft`, `다음 주`에 `ChevronRight` 아이콘을 함께 둔다. 요청 중 `disabled`는 그대로.
   - 가운데 기간 글자(`YYYY-MM-DD ~ YYYY-MM-DD`)를 담은 요소에 `font-medium`.
2. 세 구역 (`이번 주 노트`, `결정 사항`, `남은 할 일`)
   - `<section aria-label="...">`과 `<h2>` 글자는 그대로 두고, 각 구역을 `Card`로 보여 준다.
   - `h2`는 `h2` 그대로, `CardHeader` 안에서 `className="text-base font-semibold"`로 보인다 (`CardTitle`은 div이므로 heading 대신 쓰지 않는다).
   - `이번 주 노트`·`결정 사항` 구역은 `grid`와 `lg:grid-cols-2`를 가진 공통 조상 안에 둔다. `남은 할 일`은 그 grid 밖에 전체 폭으로 둔다.
3. 행
   - 노트 행과 결정 행은 노트를 여는 `Button variant="ghost"`. 긴 글자가 넘치지 않게 행 폭과 줄바꿈을 맞춘다.
   - 남은 할 일 행은 지금처럼 버튼이 아니다.
4. 상태
   - 로딩: 기존 `불러오는 중…` 문구를 지우지 않고 그 옆에 `Skeleton` 3줄을 함께 둔다 (처음 불러올 때와 다른 주로 이동할 때 모두). 응답이 오면 사라진다.
   - 오류: 기존 `role="alert"` 영역을 `Alert variant="destructive"`로 바꾼다. 문구 그대로, 기존 `다시 시도` 버튼은 `Button variant="outline"`.
   - 빈 목록: 세 구역의 `없음` 문구를 점선 영역(`border border-dashed rounded-lg p-8 text-center`)에 둔다.

## 바꾸지 않는 것

`fetchWeekly` 호출과 요청·실패 처리, 주 계산, `onOpenNote`, 모든 문구·aria-label·버튼 이름, 기존 테스트(`Weekly.J014`, `Weekly.J015`), `src/components/ui/`, 의존성.
