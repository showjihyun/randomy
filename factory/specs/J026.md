# J026 한국어 줄바꿈과 노트 저장 시각 표시 (계획 P004 작업 A)

DESIGN.md 3장(v2·v2.1)의 줄바꿈과 날짜 규칙을 적용한다.

## 만들 것

1. `frontend/src/styles.css`의 `@layer base` 안 `body` 규칙에 `break-keep`을 더한다.
2. 새 파일 `frontend/src/lib/format.ts`에 `export function formatDateTime(iso: string): string`을 둔다.
   - 결과는 `new Intl.DateTimeFormat("ko-KR", { dateStyle: "medium", timeStyle: "short" }).format(new Date(iso))`이다.
   - 잘못된 날짜 문자열이면 예외를 내지 않고 받은 문자열을 그대로 돌려준다.
3. `frontend/src/App.tsx`의 노트 목록 행과 노트 상세의 `<time>` 글자를 `formatDateTime(created_at)`으로 바꾼다. `dateTime` 속성은 ISO 원문 그대로 둔다.

## 바꾸지 않는 것

할 일 기한 글자(사용자가 입력한 글자), 주간 범위, `Organize`·`Search`·`Weekly`, 저장 형식(ISO), API, 의존성, `<time>`의 클래스, 그 밖의 문구와 동작.

## 기존 테스트 변경

표시 형식이 바뀐 데 따른 변경만 한다. 두 파일 모두 시각 글자의 기대값을 같은 `Intl.DateTimeFormat`으로 계산하도록 바꿨고, 노트 순서·상세 열기 등 다른 확인은 그대로다.
