# J028 주간 정리 행에 DESIGN.md v2 2열 표·카드 여백 적용 (계획 P004 작업 C)

`frontend/src/Weekly.tsx`의 모양만 DESIGN.md 3장 '2열 표(v2)'·'카드 여백(v2)'에 맞춘다. 동작·문구·aria-label은 바꾸지 않는다.

## 만들 것

1. `이번 주 노트`·`결정 사항`의 행 (지금처럼 노트를 여는 `Button variant="ghost"`)
   - 행 버튼에 `flex-col sm:flex-row items-start px-4 py-3`를 준다. 지금의 `h-auto w-full justify-start whitespace-normal break-words text-left`는 유지한다.
   - 제목 요소(노트 제목 / 결정 문구): `shrink-0 min-w-32 font-medium`. 긴 제목이 카드를 넘지 않도록 `max-w-full sm:max-w-1/2`도 준다.
   - 보조 글 요소(요약 / 노트 제목): `text-muted-foreground flex-1 min-w-0`. 요약이 없는 노트에는 보조 글 요소를 두지 않는다.
   - 제목과 보조 글 사이의 공백은 지금처럼 남겨 버튼의 접근 가능한 이름(`제목 보조 글`)이 바뀌지 않게 한다.
2. `이번 주 노트`·`결정 사항`의 `Card` 여백
   - `Card`에 `py-0 gap-0`을 준다.
   - 행이 있을 때 `CardContent`는 `px-0`이고, 목록(`ul` / 결정의 `div`)은 `divide-y`로 행을 나눈다 (지금의 `flex flex-col gap-1` 대신).
   - `heading()` 함수와 그 결과(`CardHeader`, `h2`)는 고치지 않는다. `Card`에 `py-0`을 주면 머리글 위 여백이 없어지므로, 두 카드에서 `heading(...)` 호출을 여백을 가진 `div`(`pt-6 pb-3`)로 감싼다.
   - 행이 없을 때의 `없음` 점선 영역은 카드 가장자리에 붙지 않게 `CardContent`에 `px-6 pb-6` 여백을 둔다.
3. `남은 할 일`
   - `담당: …`·`기한: …`을 각각 `@/components/ui/badge`의 `Badge variant="secondary"`로 보여 준다. 글자는 그대로다.
   - 할 일 글자와 배지가 나란히 간격을 두도록 `li`는 `flex flex-wrap items-center gap-2`로 하고 `break-words`는 유지한다.
   - `Card`의 여백과 목록 구조는 바꾸지 않는다.

## 바꾸지 않는 것

주 이동 줄, `heading()`, `fetchWeekly` 호출과 요청·실패 처리, 주 계산, `onOpenNote`, 모든 문구·aria-label·버튼 이름, 기존 테스트(`Weekly.J014`, `Weekly.J015`, `Weekly.J024`), `src/components/ui/`, 의존성.
