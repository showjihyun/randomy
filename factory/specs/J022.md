# J022 정리 화면에 DESIGN.md 적용 (계획 P003 작업 B)

`frontend/src/Organize.tsx`의 마크업과 클래스만 바꾼다. 상태, 핸들러, API 호출, 문구, 역할, aria-label은 그대로 둔다. 기준은 `DESIGN.md` 3·4·6·7장이다.

## 만들 것

컴포넌트는 `@/components/ui/`에 있는 것만, 아이콘은 `lucide-react`의 `Loader2`(`size-4 animate-spin`, 버튼 글자 앞)만 쓴다. 색·간격은 토큰 클래스와 4px 눈금만 쓰고 `#hex`·인라인 style은 쓰지 않는다.

1. 원문 입력: `Textarea` (`aria-label="원문"`, `min-h-56`).
2. `정리` 버튼: `Button` (default). 요청 중(`busy`)이면 `Loader2`를 글자 앞에 둔다. `disabled` 조건은 지금과 같다 (`raw.trim() === "" || busy`). `Button`은 원문 아래 오른쪽에 둔다.
3. 오류: `Alert variant="destructive"` (`role="alert"`). `error.head`는 `AlertTitle`, `error.lines`는 `AlertDescription` 안의 `<p>`로 둔다. 자리는 지금처럼 `정리` 버튼 아래다.
4. 정리 결과 편집은 `Card` 하나다. 위에서 아래로:
   - 제목 `Input`(`aria-label="제목"`), 요약 `Textarea`(`aria-label="요약"`)
   - `Separator` (decorative 기본값)
   - `결정 사항` h3 (`text-base font-semibold`), 목록(행마다 `Input` + 빼기 `Button variant="ghost" size="sm"`), `결정 추가` `Button variant="outline" size="sm"`
   - `Separator`
   - `할 일` h3 (`text-base font-semibold`), 목록(행마다 할 일·담당·기한 `Input` 3칸 + 빼기 `Button variant="ghost" size="sm"`), `할 일 추가` `Button variant="outline" size="sm"`
   - 맨 아래 오른쪽 `저장` `Button` (default). 저장 버튼을 감싼 요소에 `justify-end`를 준다. 요청 중(`saving`)이면 `disabled` + `Loader2`.
5. 할 일 3칸은 한 grid 요소의 자식이다: `grid gap-2 sm:grid-cols-[2fr_1fr_1fr]`. `sm` 미만에서는 세로 한 줄씩 쌓인다. `grid-cols-[2fr_1fr_1fr]`을 접두어 없이 쓰지 않는다. 빼기 버튼은 이 grid 밖에 둔다.
6. `없음` 문구는 글자 그대로 두고 `text-sm text-muted-foreground`를 준다.
