# J021 실행기 (실제 사용 편의, J020 다시)

백엔드와 프론트엔드를 한 번에 띄우고 브라우저를 여는 실행기를 만든다.

## 만들 것

1. `backend/src/randomy/launcher.py`
   - 레포 루트(이 파일 기준 `parents[3]`) 기준으로
     - 백엔드: `backend` 폴더에서 `uv run uvicorn randomy.main:app_from_env --factory --app-dir src --port 8000`
     - 프론트엔드: `frontend` 폴더에서 `npm run dev -- --port 5173 --strictPort`
     - 이 순서(백엔드 먼저)로 띄운다.
   - `find_executable(name: str, path: str | None = None) -> str | None`: 실행 파일의 실제 경로를 찾는다. `path`는 `PATH`와 같은 형식이고, `None`이면 환경변수 `PATH`. Windows(`os.name == "nt"`)에서는 디렉터리마다 `PATHEXT` 확장자(.COM .EXE .BAT .CMD 등)를 붙인 이름을 확장자 없는 이름보다 먼저 찾는다. 실행 인자의 첫 항목(`uv`, `npm`)은 이 함수로 찾은 경로다.
   - 환경변수 `RANDOMY_MODEL`이 없으면 `claude-cli:sonnet`, 있으면 그대로, `--model <값>`이 있으면 그 값. 자식 프로세스 env에 넣는다.
   - 두 프로세스를 띄운 뒤 `http://localhost:8000/api/health`가 응답할 때까지 최대 60초 기다리고 `http://localhost:5173`을 기본 브라우저로 연다 (`--no-browser`면 열지 않는다).
   - 두 번째 프로세스 실행이 실패(예외)하면 먼저 띄운 프로세스를 끝내고 오류를 출력한 뒤 종료 코드 1.
   - Ctrl+C나 한쪽 종료 때는 다른 쪽도 끝낸다. Windows는 자식 트리까지 (예: `taskkill /T /F /PID`).
   - `main(argv: list[str] | None = None, *, spawn=..., stop=..., open_browser=..., wait_health=...) -> int`
     - `spawn(args: list[str], cwd: Path, env: dict[str, str])` → `poll()`/`wait()`/`terminate()`/`kill()`을 가진 프로세스 객체 (기본: `subprocess.Popen`)
     - `stop(proc)`: 프로세스(트리) 종료 (기본: Windows는 트리 종료, 그 밖은 terminate 후 기다렸다 kill)
     - `open_browser(url: str)` (기본: `webbrowser.open`)
     - `wait_health(...)` → bool (기본: health URL을 60초까지 폴링)
   - `python -m randomy.launcher [--no-browser] [--model 값]`으로 실행된다.
2. 레포 루트 `start.cmd`: ASCII 문자만 (주석은 영어). `%~dp0` 기준으로 `backend\src`를 `PYTHONPATH`에 넣고 `uv run --project backend python -m randomy.launcher %*`를 실행한다.
3. `.gitattributes`에 `*.cmd text eol=crlf` 한 줄 추가.
4. `README.md` 명령 절에 `start.cmd` 사용법 두 줄.
