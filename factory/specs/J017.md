# J017 찾기 사용자 흐름 e2e 테스트 (F3)

계획 P002 작업 B. 이미 구현된 찾기 화면(`frontend/src/Search.tsx`)의 사용자 흐름을 Playwright로 확인하는 테스트 `frontend/e2e/search.J017.accept.e2e.ts`만 추가한다. 앱 코드는 바꾸지 않으므로 type은 refactor이고, 수락 테스트는 처음부터 Green이어야 한다.

## 흐름

1. 테스트 시작 시 `request.post("/api/organized")`로 고유 키워드(`Date.now()`)가 제목·원문·결정에 들어간 노트를 만든다 (201, 응답의 `note.id`·`note.title`을 쓴다).
2. `POST /api/ask`만 `page.route("**/api/ask")`로 가로채 정해 둔 `{answer, sources: [{id, title, created_at}]}`를 돌려주고 요청 본문을 모은다. 다른 요청은 가로채지 않는다.
3. 검색: 「찾기」 탭 → `검색어`에 키워드 → `검색`. region `노트 결과`에 노트 제목이 든 버튼, region `결정 사항 결과`에 결정 문구가 든 버튼이 보인다. 노트 결과 버튼을 누르면 제목 heading과 원문이 보인다.
4. 질문: 다시 「찾기」 탭 → `질문`에 질문 → `질문` 버튼. region `답변`에 답변 문구와 근거 노트 제목 버튼이 보이고, 가로챈 요청 본문 목록이 `[{question}]`이다. 근거 노트 버튼을 누르면 그 노트 상세가 열린다.

## 제약

앱 코드(frontend/src, backend), `frontend/playwright.config.ts`, `package.json`은 바꾸지 않는다. 새 패키지 없음.
