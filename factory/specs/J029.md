# J029 할 일 기한 글자를 날짜로 해석 (P005 작업 A)

할 일의 자유 글 기한을 날짜로 바꾸는 순수 함수를 새 모듈에 만든다. 규칙의 근거는 `PRODUCT.md` 4장의 `due_date` 해석 규칙이다.

## 만들 것

`backend/src/randomy/due_dates.py`

```python
def parse_due(text: str | None, base: date) -> date | None: ...
```

앞뒤 공백은 무시한다. 해석 규칙:

1. `YYYY-MM-DD`, `YYYY.MM.DD`, `YYYY/MM/DD` → 그 날짜.
2. `M월 D일` (`11월 11일`, `11월11일`) → base와 같은 해. 그 날짜가 base보다 앞이면 다음 해.
3. `M/D` → 2와 같다.
4. `오늘`·`내일`·`모레` → base, +1, +2.
5. 요일 `월요일`~`일요일` (앞에 `이번 주`가 붙어도 같다) → base 이후 가장 가까운 그 요일. base가 그 요일이면 base.
6. `다음 주 X요일` → base가 속한 주(월요일 시작)의 다음 주 X요일.
7. 글자 안에 위 형식이 섞여 있으면 (`11월 11일까지`, `금요일 오전`) 그 부분으로 해석한다.
8. 해석하지 못하면 None (`11월 둘째 주`, `미정`, 빈 글자, None). 잘못된 날짜(`2월 30일`)도 None.

모델을 부르지 않고 표준 라이브러리만 쓴다.
