# J005 할 일 목록 화면

기획안 12.2 작업 6b, F2(할 일). J004의 할 일 API(`GET /api/todos`, `PATCH /api/todos/{id}`)를 쓰는 화면. 할 일 추가 화면은 범위 밖이다.

## 요구사항

- 화면 위쪽(`Randomy` 제목 아래)에 탭 버튼 두 개 '노트'와 '할 일'을 둔다 (role `button`, 이름이 정확히 '노트' / '할 일'). 탭 버튼은 목록(`<ul>`/`<li>`) 밖에 둔다. 첫 화면은 '노트' 탭이다.
- '노트' 탭은 지금의 노트 목록·상세 화면(J002) 그대로다.
- '할 일' 탭을 누르면 `GET /api/todos`로 받은 할 일을 목록(`<ul>`/`<li>`, role `list`/`listitem`)으로 보여 준다.
  - 순서는 서버가 준 순서 그대로다 (서버가 완료 안 된 것을 먼저 준다).
  - 할 일 항목마다 내용(`task`), 담당(`owner`가 있으면 '담당: <owner>'), 기한(`due`가 있으면 '기한: <due>'), 완료 체크박스(`<input type="checkbox">`, `done`이면 체크됨)를 보여 준다. `owner`/`due`가 null이면 그 문구('담당:' / '기한:')를 보여 주지 않는다.
  - 체크박스의 접근 가능한 이름에 `task`가 들어간다 (예: `<label>`로 감싸기 또는 `aria-label`).
  - 완료된 할 일의 `task` 글자는 `<s>` 요소 안에 넣어 줄을 긋는다. 완료 안 된 할 일의 `task`는 `<s>` 안에 넣지 않는다.
  - 할 일 항목마다 '원본 노트' 버튼(role `button`, 이름 정확히 '원본 노트')이 있다.
- 체크박스를 바꾸면 `PATCH /api/todos/{id}`에 JSON 본문 `{"done": <새 값>}`을 보내고, 끝나면 `GET /api/todos`로 목록을 다시 불러와 보여 준다.
- '원본 노트' 버튼을 누르면 '노트' 탭으로 바뀌고 `GET /api/notes/{note_id}`로 그 노트의 상세를 연다 (J002 상세 화면 재사용: 제목 heading, 본문, '목록으로'). 노트를 불러오지 못하면 J002와 같이 '노트를 찾을 수 없습니다'.
- 할 일이 없으면 '할 일이 없습니다'를 보여 준다.
- '할 일' 탭에서 '노트' 탭을 누르면 노트 목록이 다시 보인다.
- 서버 연결 표시(`role="status"`)와 `Randomy` 제목은 탭과 관계없이 그대로 보인다.
- 기존 테스트(`App.test.tsx`, `App.J002.accept.test.tsx`, `e2e/`)는 바꾸지 않고 통과해야 한다. J002 테스트의 가짜 서버는 `/api/todos`에 404를 주므로, 첫 화면에서 할 일을 미리 불러오더라도 실패가 노트 화면을 깨뜨리면 안 된다.

## 제약

- 새 npm 패키지를 추가하지 않는다. 탭 전환은 React 상태로 한다.
- 백엔드는 바꾸지 않는다.
- API 호출은 `frontend/src/api.ts`에 둔다.
