# J025 앱 껍데기와 노트·할 일 화면에 DESIGN.md 적용 (계획 P003 작업 A)

`frontend/src/App.tsx` 한 파일의 JSX 구조와 className만 DESIGN.md(3·4·7장)에 맞춘다. 상태(`tab`, `view`, `notes`, `todos`, 작성 중 값)와 핸들러, API 호출, 문구는 바꾸지 않는다.

## 만들 것

컴포넌트는 `src/components/ui/`의 것을 쓴다 (`@/components/ui/...`). 새 파일을 만들지 않는다.

1. 껍데기
   - `<div class="min-h-screen lg:flex">` 안에 `<aside class="lg:w-56 lg:border-r bg-sidebar">`와 `<main class="flex-1">`을 나란히 둔다. `main` 안 `<div class="mx-auto max-w-4xl px-4 py-6 lg:px-8 lg:py-8">`이 본문이다.
   - `aside` 위쪽에 앱 이름 `<h1 class="text-lg font-semibold">Randomy</h1>`(h1은 화면에 하나)과 기존 한 줄 설명(`text-xs text-muted-foreground`), 아래에 탭 버튼들. 좁은 화면에서는 같은 `aside`가 위쪽 헤더와 가로 탭 줄(`px-4`)이 되고, 1024px 이상에서 세로 탐색 바가 된다. 전환은 `lg:` 클래스로만 하고 화면 폭을 JS로 읽지 않는다.
   - 탭은 `[{tab, label, icon}]` 배열을 map한다. 탭들의 공통 부모는 `flex`와 `lg:flex-col`을 갖는다. 탭을 `ul`/`li`로 감싸지 않는다 (기존 테스트가 listitem 수를 센다).
   - 탭은 `Button variant="ghost"` + 아이콘(`NotebookPen`, `ListTodo`, `Search`, `CalendarRange`) + 글자. 선택된 탭(`tab` 상태 기준)에는 `aria-current="page"`와 `bg-accent text-accent-foreground font-medium`을 주고, 다른 탭에는 주지 않는다. 역할은 button 그대로다. lucide의 `Search`는 `./Search` 컴포넌트와 이름이 겹치므로 별칭으로 가져온다.
   - 360px 폭에서 탭 4개가 가로 스크롤 없이 한 줄에 들어가야 한다 (DESIGN.md 3장).
   - `role="status"` 문구는 본문 영역 맨 위에 `text-sm text-muted-foreground`.
   - `Organize`·`Search`·`Weekly`는 본문 영역 안에 그대로 렌더링하고 내부는 바꾸지 않는다.
2. 공통 빈 상태: App.tsx 안의 작은 함수 컴포넌트 `EmptyState({children})` (`border border-dashed rounded-lg p-8 text-center`).
3. 노트 목록: `h2` '노트'(`text-2xl font-semibold tracking-tight`) 줄(`flex justify-between`) 오른쪽에 `새 노트`(outline)·`정리`(default). 그 아래 `Card` 안 목록(`ul`/`li` 유지). 행은 노트를 여는 버튼(`hover:bg-accent`): 제목 `font-medium`, 오른쪽 `time`은 `text-xs text-muted-foreground`. 빈 목록은 `EmptyState`에 기존 문구.
4. 노트 작성: `Card` 안 `form`. `Label`+`Input`(제목), `Label`+`Textarea`(본문, `min-h-48`), 아래 오른쪽(`justify-end`)에 `취소`(outline, type=button), `저장`(default, type=submit, 기존 disabled 조건 유지) 순서. 저장 실패는 `Alert variant="destructive"` 안에 기존 문구.
5. 노트 상세: `h2`(제목, 3번과 같은 크기) + `time`(`text-xs text-muted-foreground`), 본문 `Card`(`whitespace-pre-wrap leading-7`), `목록으로`(outline). 찾지 못함 문구도 `Card` 안에 두고 아래에 `목록으로`(outline).
6. 할 일: `h2` '할 일'(3번과 같은 크기), `Card` 안 목록(`ul`/`li` 유지). 행은 `label` 안의 기존 `input type="checkbox"` + 할 일 글자, 담당·기한은 `Badge variant="secondary"`(`담당: …`, `기한: …`, 값이 없으면 없음), `원본 노트`는 `Button variant="ghost" size="sm"`. 완료면 기존 `s` 요소에 `line-through text-muted-foreground`. 빈 목록은 `EmptyState`에 기존 문구.
