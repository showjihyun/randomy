# J018 주간 정리 사용자 흐름 e2e (F4)

계획 P002 작업 C. F4(주간 정리) 화면은 J011(API)·J014(화면)·J015(요청 중 상태)로 이미 구현돼 있다. 제품 수락 기준(기능마다 사용자 흐름 테스트 1개 이상)을 채우기 위해 Playwright 사용자 흐름 테스트 `frontend/e2e/weekly.J018.accept.e2e.ts`만 추가한다. 앱 코드는 바꾸지 않으므로 type은 refactor이고, 수락 테스트는 처음부터 Green이어야 한다.

## 흐름

1. `request`로 `POST /api/organized`를 불러 고유 문자열(`Date.now()`)이 들어간 노트를 결정 1개, 할 일 2개와 함께 만든다.
2. `PATCH /api/todos/{id}`(`{done: true}`)로 할 일 하나를 완료로 바꾼다.
3. `GET /api/weekly`(날짜 없음 = 오늘)의 `start`·`end`를 이번 주 기준으로 삼는다.
4. 「주간 정리」 탭(App.tsx 라벨 `주간 정리`)을 연다.
   - 기간 표시에 `start`와 `end`가 보인다.
   - region `이번 주 노트`에 만든 노트 제목 버튼, region `결정 사항`에 만든 결정 버튼이 보인다.
   - region `남은 할 일`에 완료하지 않은 할 일 listitem이 보이고, 완료한 할 일은 보이지 않는다.
5. 「지난주」를 누르면 기간 표시가 `start-7일`·`end-7일`로 바뀌고 `이번 주 노트`에 만든 노트가 없다.
6. 「다음 주」를 누르면 기간이 `start`·`end`로 돌아오고 만든 노트가 다시 보인다.

## 제약

- 앱 코드(frontend/src, backend), `frontend/playwright.config.ts`, `package.json`은 바꾸지 않는다. 새 패키지 없음.
- 모델을 쓰지 않으므로 `page.route`로 가로채지 않는다.
