# J001 노트 저장·목록 API

기획안 12.2 작업 1, F1(회의록·메모 정리)의 저장 부분. 화면은 범위 밖이다.

## 요구사항

- `POST /api/notes` 본문 JSON `{"title": str, "body": str}`.
  - `body`가 빈 문자열이거나 없으면 422.
  - 성공하면 201과 `{"id", "title", "body", "created_at"}`을 돌려준다. `created_at`은 ISO 8601 문자열이다.
- `GET /api/notes`: 저장된 노트 목록을 최신순(나중에 저장한 것이 먼저)으로 돌려준다. 각 항목은 POST 응답과 같은 필드를 가진다. 같은 시각에 저장된 노트도 나중에 저장한 것이 먼저 온다.
- `GET /api/notes/{id}`: 노트 하나. 없으면 404.
- 저장소는 `Settings.db_path`의 SQLite 파일(표준 라이브러리 `sqlite3`). 같은 `db_path`로 앱을 다시 만들어도 노트가 남아 있다.

## 제약

- `settings.py`, `model.py`는 바꾸지 않는다.
- 새 의존성을 추가하지 않는다.
- 모델을 호출하지 않는다.
