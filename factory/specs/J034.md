# J034 할 일 마감 표시와 좁은 화면 수정 (P005 작업 D)

`DESIGN.md` v3의 "마감 표시"와 탭 줄 규칙을 적용하고, J033 미리보기에서 사람이 확인한 월 제목 줄바꿈을 고친다. 새 npm 패키지는 쓰지 않는다.

## 1. `frontend/src/lib/due.ts` (새 파일)

`export function dueStatus(dueDate: string | null, done: boolean, today: string): "overdue" | "today" | "soon" | null`

- `dueDate`, `today`는 `YYYY-MM-DD`다. 완료했거나(`done`) `dueDate`가 `null`이면 `null`.
- `dueDate`까지 남은 **달력 일수**로 판정한다: 0보다 작으면 `overdue`, 0이면 `today`, 1~3이면 `soon`, 그 밖에는 `null`.
- 일수는 시간대·서머타임의 영향을 받지 않게 계산한다 (`Date.UTC(연, 월-1, 일)`의 차이를 86400000으로 나눈다). `new Date("YYYY-MM-DD")`와 로컬 시각을 섞지 않는다.

## 2. `frontend/src/App.tsx` 할 일 행

할 일 행의 기한 원문 배지(`기한: {todo.due}`, `variant="secondary"`) **바로 다음 형제**로 상태 `Badge`를 놓는다.

| `dueStatus` | `variant` | 글자 |
|---|---|---|
| `overdue` | `destructive` | 기한 지남 |
| `today` | `default` | 오늘 |
| `soon` | `outline` | 곧 |
| `null` | 붙이지 않음 | |

`today` 인자는 브라우저 **로컬** 날짜의 `YYYY-MM-DD`다 (`getFullYear`·`getMonth`·`getDate`로 만든다. `toISOString`은 시간대에 따라 하루 어긋난다). 원문 배지의 글자와 variant, 담당 배지, `원본 노트` 버튼은 바꾸지 않는다.

## 3. `frontend/src/App.tsx` 탭 줄 (1024px 미만)

탭 버튼의 이름·순서·동작·선택 표시는 그대로 두고 className만 더한다.

- 글자: `text-xs lg:text-sm`
- 쌓기: `flex-col sm:flex-row` (639px까지 아이콘 위·글자 아래, 640px부터 가로)
- 높이: `h-auto sm:h-8` (쌓인 상태에서 `size="sm"`의 `h-8`을 넘치지 않게 한다. 640px 이상은 지금 높이)

1024px 이상의 모양(`lg:flex-none lg:justify-start`, `text-sm`)은 그대로다.

## 4. `frontend/src/Calendar.tsx` 월 제목

제목 heading `YYYY년 M월`에 `whitespace-nowrap`을 더한다 (`text-lg font-semibold`는 유지). 제목이 줄바꿈하지 않아도 360px에서 줄이 넘치지 않도록 이동 버튼 3개(`이전 달`, `다음 달`, `오늘`)의 글자를 `text-xs sm:text-sm`으로 줄인다. 버튼의 접근 가능한 이름과 동작은 바꾸지 않는다.

## 바꾸지 않는 것

백엔드, 의존성, `DESIGN.md`, 기존 테스트, 탭의 이름·순서·동작, 기한 원문 배지, 그 밖의 화면. 할 일 정렬도 바꾸지 않는다.
