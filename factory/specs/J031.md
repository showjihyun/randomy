# J031 할 일 응답의 due_date와 캘린더 API (P005 작업 B)

J029의 `parse_due`를 API에 연결하고, 달력 화면(작업 C·D)이 읽을 캘린더 API를 만든다. DB 스키마는 바꾸지 않고 조회할 때 계산한다.

첫 시도 J030은 잠긴 J008이 저장 응답과 목록 응답의 일치를 확인해 막혔다. 이번에는 사람 결정(2026-11-08)대로 **할 일을 돌려주는 모든 응답에 같은 `due_date`를 넣고**, 기존 테스트 세 개의 `TODO_FIELDS`만 Spec 단계에서 바꾼다.

## 1. 할 일 응답의 due_date

`TodoOut`에 `due_date: str | None`(ISO `YYYY-MM-DD`, 기본값 없는 필수 필드)을 더한다. 응답 모델을 나누지 않는다.

넣는 곳: `GET /api/todos`, `PATCH /api/todos/{id}`, `POST /api/notes/{id}/todos`, `POST /api/organized`의 `todos`, `GET /api/weekly`의 `open_todos`.

값은 `due_dates.parse_due(due, 기준일)`이다. 기준일은 그 할 일의 `note_id` 노트 `created_at`을 로컬 시간대(`tz`, 기본 서버 로컬, weekly와 같은 방식)로 바꾼 날짜다. 할 일 행의 `created_at`은 기준일에 쓰지 않는다.

설계 (사람 합의):

- `todos.py`: 할 일 행을 `TodoOut`으로 바꾸는 공통 함수 `to_todo_out(row, note_created_at, tz)`를 두고 todos·organized·weekly가 함께 쓴다.
- 조회는 `todos JOIN notes`로 `created_at AS note_created_at`을 읽는다. 할 일의 `id`·`created_at`이 노트 값으로 덮이면 안 된다.
- `create_todos_router(db_path, tz=None)`, `create_organized_router(db_path, tz=None)`, `create_weekly_router(db_path, tz=None)`. 기존 함수 `weekly(db_path, day, tz)`의 `tz`도 `open_todos`에 쓴다.

## 2. 기존 수락 테스트

`backend/tests/acceptance/test_J004.py`, `test_J008.py`, `test_J011.py`의 `TODO_FIELDS` 집합에 `"due_date"`를 더하는 것만 바꾼다. 다른 확인은 바꾸지 않는다.

## 3. 캘린더 API

새 모듈 `backend/src/randomy/calendar_view.py`.

```python
def calendar(db_path: Path, month: str | None, tz: tzinfo | None) -> CalendarOut: ...
def create_calendar_router(db_path: Path) -> APIRouter: ...
```

`GET /api/calendar?month=YYYY-MM` (없으면 오늘이 속한 달, 형식이 틀리면 422):

```text
{
  "month": "YYYY-MM",
  "days": [
    {
      "date": "YYYY-MM-DD",
      "notes": [{"id": 1, "title": "..."}],
      "decisions": [{"text": "...", "note_id": 1, "note_title": "..."}],
      "todos": [{"id": 1, "task": "...", "done": false, "note_id": 1, "due": "...", "due_date": "YYYY-MM-DD"}]
    }
  ]
}
```

- 노트·결정은 노트 `created_at`의 로컬 날짜로 넣는다. 할 일은 `due_date`가 그 달에 있는 것만 넣는다.
- 항목이 있는 날만 날짜 순으로 넣는다.
- `month`는 `YYYY-MM` 형식, 월은 1~12만 받는다. 노트는 전체를 읽어 파이썬에서 로컬 날짜로 거른다. 결정은 `decisions JOIN notes`, 할 일은 `todos JOIN notes`에서 `due_date`를 계산해 거른다.
- `main.py`에 라우터를 등록한다.
