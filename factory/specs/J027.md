# J027 찾기 화면 결과 목록 카드 여백 (계획 P004 작업 B)

`frontend/src/Search.tsx` 한 파일의 className만 DESIGN.md 3장 '카드 여백 (v2)'에 맞춘다. 상태·핸들러·API 호출·문구·aria-label·역할은 바꾸지 않는다.

## 만들 것

1. '노트 결과'·'결정 사항 결과'에서 결과 행이 있는 목록을 담는 `Card`: 지금의 `px-2`를 `py-0 gap-0`으로 바꾼다.
2. 그 목록의 `ul`에 `divide-y`를 준다.
3. 결과 행 버튼(`renderRow`의 `Button`)에 `px-4 py-3`을 더한다. 기존 클래스(`h-auto`, `whitespace-normal` 등)는 유지한다.

## 바꾸지 않는 것

- 검색·질문 폼 `Card`와 답변 `Card` (`px-6` 그대로).
- 결과가 0건인 쪽의 `Card` (`px-2` 그대로, 안에 점선 영역). 행이 없으므로 '목록을 담는 Card'가 아니다.
- 기존 테스트(`Search.J013`, `Search.J015`, `Search.J023`), `src/components/ui/`, 의존성.
