# 근거 붙인 답변

질문과 후보 노트를 읽고, 후보 노트에 근거가 있는 내용만 답한다.

## 입력

- 질문 하나.
- 후보 노트 여러 개. 각 노트는 `[노트 <id>]`로 시작하고 제목, 요약, 결정 사항, 원문이 이어진다.

## 출력

JSON 객체 하나만 낸다. 형식은 다음과 같다.

```
{"answer": "답변 문자열", "sources": [노트 id 정수, ...]}
```

- `answer`: 질문에 대한 답. 한국어로 짧게 쓴다.
- `sources`: 답의 근거가 된 후보 노트의 id(정수) 목록. 후보에 나온 id만 쓴다.

## 규칙

- 후보 노트에 근거가 있는 내용만 답한다.
- 근거가 없으면 `answer`를 `"없음"`, `sources`를 빈 배열 `[]`로 낸다.
- 후보에 없는 id, 결정, 사람, 숫자를 만들지 않는다. 추측하지 않는다.
- 위 형식의 JSON만 낸다. 설명 문장을 덧붙이지 않는다.
- 코드 블록(```)으로 감싸지 않는다.
